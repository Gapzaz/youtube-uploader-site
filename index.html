Personal project

YouTube video upload automation

This website describes a personal automation project that uploads video files to the owner's YouTube channel using the YouTube Data API.

What the application does

  • Uploads video files selected by the owner to the owner's YouTube channel.
  • Uses Google OAuth 2.0 to obtain permission to access the owner's YouTube account.
  • May set uploaded videos to private, according to the owner's local script configuration.
  • Runs on the owner's own computer or server; this website does not provide an upload service to visitors.

Who operates this project?

This is a personal project operated by its owner, not a public service for other users.

Privacy

This website is a static information page. It does not provide sign-in forms, collect video files, or intentionally collect personal information through forms.

For information about the local automation script and its use of Google/YouTube data, read the Privacy Policy.
