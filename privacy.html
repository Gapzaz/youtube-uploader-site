Privacy Policy

Last updated: October 17, 2026

This policy describes the personal YouTube upload automation script operated by its owner (“the application”). The script runs on the owner's own computer or server and uses Google OAuth 2.0 and the YouTube Data API.

Information the application accesses

When the owner authorizes the application, it may access Google/YouTube account data permitted by the OAuth scopes granted to it. The script uses this access to upload video files and, where configured, manage uploaded video details or playlists on the owner's YouTube channel.

The script processes video files and associated information such as video titles, upload status, and YouTube video identifiers. The exact operations depend on the local script configuration.

How information is used

  • To upload the owner's selected videos to the owner's YouTube channel.
  • To track which files have been uploaded and avoid unintended repeat uploads.
  • To perform other YouTube actions explicitly configured by the owner in the local script.

Storage and sharing

OAuth credentials, tokens, upload records, and video files are intended to be stored on the owner's own computer or server. The owner is responsible for securing that system and its backups. The application operator does not offer a separate hosted service that collects visitors' video files.

The application does not sell personal information. Data is sent to Google/YouTube as needed for the authorized API operations and is handled by Google under its own policies. The static website itself does not include a form for collecting personal information.

Data retention and deletion

The owner can remove local token and upload-history files from the system where the script runs. Videos already uploaded to YouTube must be managed through YouTube or the script's configured functionality. Deleting local data does not automatically delete data already held by Google/YouTube.

Security

The owner should restrict access to OAuth credential files and token files and should never publish them in a public repository. No method of storage or transmission can be guaranteed completely secure.

Children's privacy

This personal automation project is not designed to collect information from children.

Changes to this policy

This policy may be updated when the application's functionality or data handling changes. The latest version will be published on this page.
