# YouTube Uploader site

This folder contains a simple static home page and privacy policy for a personal YouTube upload automation project.

## Before publishing
1. Open `index.html` and `privacy.html`.
2. Replace `[Replace with your name or project owner label]` and `[Replace with a contact email address]` with accurate details.
3. Review the privacy policy to ensure it matches what your actual script does.
4. Do not add `credentials.json`, `token.json`, client secrets, or other private files to this repository.

## Publish with GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait for GitHub Pages to deploy. The project site URL normally looks like:
   `https://YOUR-GITHUB-USERNAME.github.io/youtube-uploader-site/`
5. Test both the home page and `/privacy.html`.

Note: a `github.io` URL is free hosting, but Google OAuth may still require a domain you own and have verified. Do not assume GitHub Pages alone satisfies every OAuth Production requirement.
